# LAIM Extract Sample

Детерминированное сэмплирование UMR перед LLM-ассесором.

## Назначение

Нода ставится между **конвертером трейсов** (выход `monitoring_umr`) и **LAIM Asessor Agent** (вход `monitoring_umr`):

```
Конвертер → [monitoring_umr] → Extract Sample → [monitoring_umr_sample] → Asessor Agent
```

Пропускает не более заданного числа примеров (turn), схему и содержимое строк не меняет.

## Параметры оператора

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|---------------|----------|
| `sample_size` | int | 1500 | Максимум примеров на выход. 0 = все примеры без ограничения |
| `seed` | int | 42 | Зерно детерминированного отбора. Фиксирует порядок выборки |
| `whole_sessions` | bool | true | Если true — сессии отбираются целиком (диалог не режется). Если false — можно брать отдельные строки внутри сессии |

## Формат входных данных

Нода работает с двумя форматами UMR:

### Packed-форма (колонка `dialogue`)
```
session_id | dialogue
-----------+------------------------------------------
s1         | [[q1, в1, о1], [q2, в2, о2], ...]   ← список turns
```
- Строка = сессия целиком
- Пример = один turn из списка `dialogue`
- `whole_sessions=true` всегда значит целые строки (сессии), т.к. диалог уже упакован

### Плоская форма (колонка `query_id`)
```
query_id | input_query | output_answer | session_id | reference_group_id
---------+-------------+---------------+------------+------------------
s1-t1    | вопрос      | ответ         | s1         | g1
s1-t2    | вопрос      | ответ         | s1         | g1
```
- Строка = один turn
- Пример = строка датафрейма
- При `whole_sessions=true` берутся целые сессии (группировка по `session_id` / `reference_group_id`)

## Логика отбора

Отбор **равномерный и воспроизводимый**:

1. Входные данные разбиваются на единицы отбора (сессии или строки)
2. Каждая единица получает хеш `sha256(f"{seed}:{ключ_сессии}")`
3. Единицы сортируются по хешу (возрастание)
4. Набираются целиком, пока влезают в `sample_size`
5. Единица, не влезающая целиком, пропускается

**Результат не зависит от порядка строк на входе** и повторяется от запуска к запуску при одинаковом `seed`.

## Обработка краевых случаев

| Ситуация | Поведение |
|----------|-----------|
| `sample_size = 0` | Все примеры передаются без изменений |
| Примеров на входе ≤ `sample_size` | Выборка передаётся целиком |
| Пустой DataFrame | Возвращается пустой DataFrame |
| `whole_sessions=true` и сессия не влезает | Сессия пропускается |
| Нет `dialogue` и нет `query_id` | Ошибка с описанием ожидаемых колонок |

## Выходной порт

| Порт | Тип | Описание |
|------|-----|----------|
| `monitoring_umr_sample` | dataframe | Не более `sample_size` примеров. Подключается ко входу `monitoring_umr` ассесора |

## Примеры

```python
import pandas as pd
from main import main

# Плоский UMR: 4 сессии по 2-4 примера
frame = pd.DataFrame([
    {"query_id": "s1-t1", "input_query": "в1", "output_answer": "о1", "session_id": "s1"},
    {"query_id": "s1-t2", "input_query": "в2", "output_answer": "о2", "session_id": "s1"},
    # ...
])

# Sample: до 5 примеров, сессии целиком
result = main(monitoring_umr=frame, sample_size=5, seed=42, whole_sessions=True)
# Сессия s1 (2 примера) + s2 (3 примера) = 5 примеров; s3 не влезла

# Sample: до 5 примеров, отдельные строки
result = main(monitoring_umr=frame, sample_size=5, seed=42, whole_sessions=False)
# Строки набираются по хешу, пока не наберётся 5
```
